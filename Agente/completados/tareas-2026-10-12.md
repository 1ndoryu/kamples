## Advisories cargo: cadena legacy de aws-sdk-s3 (feature `s3`)

`cargo audit` reportaba h2 0.3.27 (RUSTSEC-2026-0258) y rustls-webpki 0.101.7
(RUSTSEC-2026-0098/0099/0104), arrastrados por aws-sdk-s3 con la feature `rustls`
(aws-smithy-http-client con hyper 0.14 legado).

### Qué se hizo

- `Cargo.toml:112`: aws-sdk-s3 usa `default-https-client` en lugar de `rustls`.
- `Cargo.lock`: salen hyper 0.14.32, h2 0.3.27, hyper-rustls 0.24.2, rustls 0.21.12,
  rustls-webpki 0.101.7, tokio-rustls 0.24.1 y sct 0.7.1. Suben aws-sdk-s3 1.119.0 → 1.129.0
  y sus transitivos (aws-smithy-*, crc-fast, lru 0.16.4, sha2 0.11.0, spin 0.10.1).
  Esa cadena solo entra con el feature opcional `s3`; el build por defecto no la compila.

### Evidencia

- `cargo check --features s3 --tests`: EXIT 0, 0 errores, 0 warnings.
- `cargo check --tests` (por defecto): EXIT 0, 0 errores, 0 warnings.
- `cargo audit`: `vulnerabilities` solo contiene `rsa` 0.9.10 (RUSTSEC-2023-0071, sin parche).
- No probado: petición real a S3 (no hay endpoint). Evidencia solo de compilación.

## Web Push: sustituir `atomic_web_push` (advisory `rsa`)

`atomic_web_push` 0.3.0 arrastraba `rsa` 0.9.10 (RUSTSEC-2023-0071) incluso con
`default-features = false`. Se sustituye por `web-push-native` 0.5.0 (cifrado RFC 8291,
sin feature `vapid`) y la firma VAPID ES256 (RFC 8292) hecha en `src/services/push.rs`
con `p256` 0.13 (`ecdsa`). Las variantes `vapid` de `web-push-native` arrastran `jwt-simple` → `rsa`.

### Qué se hizo

- `Cargo.toml`: `atomic_web_push` → `web-push-native`, `http`, `p256`.
- `src/services/push.rs`: envío con `reqwest`; cabecera `Authorization: vapid t=<jwt>, k=<pública>`;
  404/410 → endpoint expirado; el resto → error con el código HTTP.
- `Agente/documentacion/backend/handlers-push-2026-04-18.md`: descripción del nuevo envío.

### Evidencia

- `cargo test push::tests`: 6/6 OK (clave pública derivada de la privada, rechazo de clave
  que no coincide, JWT ES256 verificado con la clave derivada, auth de suscripción de 16 bytes,
  endpoint HTTPS obligatorio, payload nulo).
- `cargo check --tests`: EXIT 0.
- No probado: envío real a un servicio push (no hay suscripción de prueba).
